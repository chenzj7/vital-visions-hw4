Alpha-channel BFSK transmitter

Bit 0 uses one alpha cycle per symbol; bit 1 uses two. The frame contains a 16-bit alternating preamble, 16-bit byte length, UTF-8 payload, and CRC-16.

Idle - start the receiver recording first.

For a measured BER, use the same message for every distance/alpha trial and pass it to receiver.py with --expected-message.
